# Scheda Personale di Postazione

## Hardware

Questa postazione di laboratorio è basata su un PC con sistema operativo Windows 11.  
È equipaggiata con un processore Intel i7 e 16 GB di memoria RAM.  

### Specifiche di Memoria

La memoria RAM garantisce la fluida esecuzione dell'ambiente di sviluppo e dei container di laboratorio.  

## Software

In questo sistema è installato Visual Studio Code versione 1.9x insieme all'ambiente di sviluppo JDK 17 per la programmazione in Java.  

Per la gestione e il controllo versione dei sorgenti è presente la CLI di **Git** versione 2.4x.  

## Credenziali di Accesso

Per l'autenticazione sui sistemi remoti viene utilizzato l'account **GitHub** personale.
